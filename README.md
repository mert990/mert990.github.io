# VisaPro — Visa Appointment Company Website

A promotional and commercial website for a visa appointment and application support company.

## What’s included

- **Hero** — Headline and call-to-action
- **Services** — Appointment booking, document preparation, visa types
- **How it works** — 3-step process
- **Why choose us** — Benefits and differentiators
- **Contact** — Form plus email/phone

## Run locally

Open `index.html` in a browser, or use a simple server:

```bash
# Python
python -m http.server 8080

# Node (npx)
npx serve .
```

Then visit `http://localhost:8080` (or the port shown).

## Customization

- **Brand name**: Replace “VisaPro” in `index.html` and in the footer.
- **Contact details**: Update the email and phone in the contact section and connect the form to your backend or email service.
- **Colors/fonts**: Edit CSS variables in `styles.css` (`:root`).

## Tech

- Plain HTML, CSS, and JavaScript
- No build step required
- Responsive layout with a mobile menu
